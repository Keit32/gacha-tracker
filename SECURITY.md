# Security Policy

This app is designed to handle sensitive data (game account cookies and tokens), so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the affected version. If you can, suggest a fix.

This is a solo-maintained hobby project, so responses are best effort. I aim to acknowledge reports within about a week. There is no bug bounty.

## Scope

In scope: the code in this repository, including credential handling, the updater and release process (once they exist), and dependency issues that affect users.

Out of scope: vulnerabilities in HoYoverse's games or services, and problems that require an already-compromised computer.

## Supported versions

Only the latest release receives security fixes.

## Reminder for everyone

Never share your cookies, tokens, authkeys, or passwords in issues, pull requests, screenshots, or logs. The maintainer will never ask for them.
